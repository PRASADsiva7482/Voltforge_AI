# Retired scale experiment

These files are preserved for historical audit only. They described, allocated,
or simulated a large decoder architecture but did not produce a compatible,
validated, trained checkpoint. They are outside the production registry,
training plan, test discovery, and runtime import graph.

Do not use their class names, parameter target, generated metrics, or export
metadata as a model capability claim. The active family identity contract is
defined in `model/identity.py`, and complete path/label mapping is recorded in
`model/legacy/retired_model_labels.json`.
